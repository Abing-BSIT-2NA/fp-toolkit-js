# FP toolkit JS

A functinal programming utility toolkit built with JavaScript.

## Description

This project Demonstrates core functional programming concepts including pure functions, immutability, higher-order functions, function composition, and currying.

## Project Structure 

-`src/arrayUtils.js` - Array transformation utilities 
-`src/mathUtils.js` - Mathematical pure functions
-`src/stringUtils.js`- String manipulation utilities
-`src/compose.js` - Function composition helpers
-`test/` - Test files for all modules

## How to Run
```bash
node index.js
node tests/arrayUtils.test.js
```
